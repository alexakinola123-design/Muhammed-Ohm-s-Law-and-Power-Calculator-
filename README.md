# Ohm's Law and Power Calculator

## What it does
A simple console program that calculates Voltage, Current, Resistance or Power using Ohm's Law and the power formulas.  
After every calculation it also shows the full set of related values (V, I, R, P) and keeps a history of previous results that you can view or clear.

## How to run it
Install Python 3, then run:
```bash
python Ohms_law_calculator.py
